OCR Scanner App - Setup & Requirements

Requirements:
1. Windows OS
2. Node.js (v18 or higher recommended) - Download from https://nodejs.org/
3. A Gemini API Key - Get one from Google AI Studio (https://aistudio.google.com/)
4. A shared network (WiFi router or Mobile Hotspot) for connecting your phone and PC.

Setup Instructions:
1. Open the file `.env.local` in this folder using Notepad.
2. Replace `your_api_key_here` with your actual Gemini API key.
3. Save and close `.env.local`.
4. Double-click on `start_app.bat`.
5. The script will automatically install any missing dependencies and start the local server.
6. A black command window will open. Leave it open while using the app.

How to use on your Mobile Phone:
1. Ensure your phone and this PC are connected to the SAME WiFi network (or connect your PC to your phone's Hotspot).
2. Look at the top of the website on your PC monitor. It will display a blue banner with a URL (e.g., http://192.168.1.5:3000).
3. Open your phone's web browser (Chrome, Safari, etc.) and type in that exact URL.
4. You can now use your phone's camera to capture images directly into the system!

Note on Database & Local Environment (Future):
This PoC currently runs completely locally without a database and displays the data on the screen. For the final project, a local database like SQLite or MySQL (via XAMPP) can be integrated seamlessly, and all processing will remain 100% local within your shop's network.
